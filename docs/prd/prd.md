# 儿童习惯打卡积分奖励平台原始需求

## 一、文档说明

本文对家长提出的高阶需求进行结构化整理，保留原始需求含义，暂不展开详细讨论、规则细化或技术方案设计。

## 二、背景与目标

家长是一位有两个孩子的爸爸，希望打造一个打卡积分奖励平台，帮助孩子们培养良好的生活和学习习惯。

平台通过每日任务打卡、积分奖励、目标奖励和虚拟养成活动，增加孩子参与和坚持打卡的动力。

## 三、孩子情况

| 孩子 | 性别 | 年龄 | 就学阶段 |
| --- | --- | --- | --- |
| 果果 | 女孩 | 12 岁 | 初一 |
| 阳阳 | 男孩 | 三岁多 | 刚上幼儿园 |

## 四、功能需求

### 4.1 独立积分账套

- 两个孩子分别拥有独立的积分账套。
- 可以切换孩子的账套进行打卡。
- 每个孩子的目标、任务池和积分账户相互关联，分别管理。

### 4.2 目标设置

- 每个孩子可以在自己的账套内独立设置打卡目标。
- 同一账套支持同时设置多个目标。
- 每个目标需要设置以下内容：

| 内容 | 说明 |
| --- | --- |
| 目标名称 | 目标的名称 |
| 目标描述 | 目标的具体描述 |
| 目标所需积分 | 达成目标需要的积分 |
| 达成奖励 | 目标达成后可以获得的奖励 |
| 每日打卡任务 | 从该孩子的任务池中选择的每日任务 |

### 4.3 独立任务池与目标任务配置

- 考虑两个孩子年龄差异较大，每个孩子拥有独立的任务池。
- 任务池与孩子的积分账户挂钩。
- 设置目标时，从对应孩子的任务池中选择每天的打卡任务。
- 每个任务自带默认完成积分。
- 在每个目标中，可以修改该任务用于本次目标的特定完成积分。
- 未录入本次目标的特定完成积分时，使用任务默认完成积分。

### 4.4 任务完成与未完成积分规则

- 完成任务可以获得该任务对应的奖励积分。
- 未完成任务可以设置为不得分，也可以设置为扣分。
- 在任务中定义未完成时的处理方式；选择扣分时，需要定义扣分数值。

| 任务情况 | 积分处理 |
| --- | --- |
| 已完成 | 获得对应的完成奖励积分 |
| 未完成，配置为不得分 | 不获得积分 |
| 未完成，配置为扣分 | 扣除配置的积分 |

### 4.5 连续打卡递增奖励

- 在目标存续期内，对连续不中断完成每日目标的行为给予递增奖励积分。
- 每个连续完成日的额外奖励可以递增 1 分。
- 如果连续打卡中断，则中断当天的递增奖励积分为 0。

### 4.6 目标与虚拟养成活动

- 每个目标的达成过程可以关联一个虚拟养成活动。
- 活动示例包括养大一只动物、种大一棵小树。
- 任务开始时，虚拟形象为动物宝宝或小树苗。
- 每天获得的积分作为虚拟动物或植物成长的养分。

### 4.7 每晚积分清算与拟人化反馈

- 每天晚上清算积分，总结当天的奖励和扣分情况。
- 总结过程采用拟人化表现，出现一位老师形象，陈述当天的积分获得情况。
- 对奖励部分，老师陈述奖励后，可以对虚拟宠物或小树做出抚摸等动作。
- 对扣分部分，老师总结后，需要对虚拟形象做出打屁股之类的惩罚动作。
- 上述互动的原始意图是激起孩子对虚拟动物或植物的保护欲，增加参与趣味。

## 五、界面与风格需求

- 整体界面风格简约、可爱。
- 两个孩子的积分操作页面可以根据性别和年龄进行差异化设计。
- 差异化设计需要考虑果果处于初中阶段、阳阳刚进入幼儿园的情况。
