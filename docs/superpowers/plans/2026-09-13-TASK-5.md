# TASK-5 按日期目标实施计划

目标：实现任务 #5 的目标创建、进行中编辑、列表和详情，覆盖 AC-09 至 AC-12，以及 #4 明确移交的 AC-08 引用行为。

架构：沿用 ADR-0001 的单一家庭习惯模块和三个公共入口；ArkUI 只维护草稿和快照。目标类型保存在领域目录，持久化沿用 ArkData 完整状态事务；模式 2 升级到模式 3。

规格：[SPEC-HABIT-001](../../specs/SPEC-HABIT-001-儿童习惯打卡积分平台.md)。用户已确认家庭习惯入口、内部持久化合约与 ArkUI 用户流程三个测试边界。

## 约束

- 中文文档、注释和错误；HarmonyOS 原生本地优先。
- 日期由调用方显式传入，领域不读取系统时钟。
- 不实现频率、打卡、清算、终止或反馈演出。
- 以目标各自初始零分及独立编辑验证 AC-11；不宣称已经验证清算后积分独立。
- 保留现有 build-profile.json5 本机修改。
- 分支 codex/TASK-5-date-goals；提交使用 feat: TASK-5 ...。

## 文件职责

- FamilyHabitModule.ts：公开命令/查询、权限、事务和迁移。
- Goals.ts：模块内目标数据类型及规则校验，不新增公开业务入口。
- tests/domain/goals.test.ts：通过会话、命令和快照验证目标行为。
- GoalPanel.ets：目标列表、详情、基本信息与任务规则编辑。
- Index.ets：家长目标入口与孩子当日任务、目标展示。
- GoalPersistence.test.ets、GoalFlow.test.ets：真实存储与 UI 合约。
